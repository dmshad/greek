# Транскрипция (генерируется tools/translit.py)
- Гласные: α — а; ε, αι — э (везде); η, ι, υ, ει, οι, υι — и; ο, ω — о; ου — у.
- αυ / ευ — ав / эв перед гласной и звонкой, аф / эф перед θ κ ξ π σ τ φ χ ψ и в конце.
- Согласная + безударное ι (ει, οι, υ) + гласная → ь + гласная: παιδιά — пэδья́, πιάτο — пья́то, ήλιος — и́льос (для всех согласных, в т. ч. λ, ν).
- Книжные слова с полным «и» — флаг S в words.txt: δωμάτιο — δома́тио, αύριο — а́врио, месяцы.
- γ — г; перед ε, αι, ι, η, υ, ει, οι, ευ — й; γι/γει + гласная → й + гласная (γεια — йа).
- δ, θ — пишутся греческими буквами. ζ — з, ξ — кс, ψ — пс, χ — х, τσ — ц, τζ — дз.
- μπ / ντ / γκ — б / д / г в начале слова, мб / нд / нг в середине (μπ перед τ — мп); γγ — нг, γχ — нх.
- σ перед β γ δ μ ν λ ρ — з. Двойные согласные — одна буква.
- Ударение — знак над гласной (калимэ́ра); односложные — без знака, кроме ή, πού, πώς.
- Исключения задаются вручную (флаг X:): συγγνώμη — сигно́ми, μπαμπάς — баба́с, φρέντο — фрэ́до, ίντερνετ — и́нтэрнэт.

# Проверка ответов
- Ударение строго: нет, лишнее (в т. ч. на односложном) или не на том слоге — ошибка с пояснением.
- σ вместо конечного ς — не ошибка; регистр, пунктуация, латиница-двойники — не ошибка.
- πού/που, πώς/πως, ή/η — разные слова (пояснение).
- «Звучит так же, пишется иначе» (ι/η/υ/ει/οι, ο/ω, ε/αι) — ошибка с пояснением.
- Энклитика (το όνομά μου) — учесть в теме 9.
